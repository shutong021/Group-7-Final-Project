# Measuring AI Patent Enforceability with Large Language Models: Evidence from Recentive

This repository contains the research proposal, presentation slides, code, and pilot output for a course final project. The project examines how the U.S. Federal Circuit's April 2025 ruling in Recentive Analytics, Inc. v. Fox Corp. — which contracts the expected enforceability of applied-only machine-learning patent claims — affects the architecture of syndicated loan contracts for AI-patenting U.S. firms.
The core measurement contribution is a patent-level Recentive Vulnerability Score constructed using a large language model (DeepSeek-Reasoner) that operationalizes the Federal Circuit's two-step Alice test as a continuous [0,1] measure of textual resemblance to Recentive-vulnerable claim language.

## How to Use This Repository
The notebook in 04_Code/ is the primary entry point. The main steps it performs are:

Setup: configure local data paths, register file locations, and initialize the DeepSeek API client.
Download Data through the public website.
Sampling: draw a stratified random sample of patents from the AI patent universe.
LLM-based scoring: apply the structured legal-reasoning prompt to each patent claim using DeepSeek-Reasoner (with DeepSeek-Chat as a robustness check) and save the resulting scores.
Aggregation and visualization: produce the figures in 03_Output/.

## Running the Code
The notebook requires:

Python 3.10+
Standard scientific stack (pandas, numpy, matplotlib, pyarrow)
The OpenAI package
A DeepSeek API key
